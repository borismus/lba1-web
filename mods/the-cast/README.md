# The Cast

A mod for [LBA1 in the browser](../../platform/web/README.md): every 3D
model in the game (FILE3D.HQR) in one place. Talk to one for its number
and the bodies it has, as you'd write them in a level file (`actor N`,
`body B`). The lines are text only.

Like every mod here it holds no game data: the level is an ASCII map, and
the page builds it from your own copy of the game.
